# everyday-conversations
To use a tool that guide to everyday conversations in order to imporve english skills.

Mecánicas de estudio y práctica

La página reúne todo lo necesario para trabajar la conversación de forma activa, con una estructura pensada para que estudiar sea dinámico y visual.
- Navegación por diálogos: la barra lateral organiza los 30 diálogos en tres unidades temáticas (Introducciones, Por la ciudad, Pasatiempos). Puedes buscar por título, tema o contenido y ver tu progreso marcando cada diálogo como completado.
- Modo de lectura y escucha: cada línea del diálogo tiene un botón de audio para escucharla por separado, o puedes usar “Escuchar todo” para una reproducción continua que resalta la línea en curso. También puedes ocultar el texto y activar un papel de la conversación (por ejemplo, ser uno de los personajes) para practicar tu turno en voz alta.
- Notas y frases clave: cada diálogo incluye notas de idioma explicadas y una lista de frases clave con su traducción al español. Los botones de audio te permiten escuchar cada frase para fijar pronunciación.
- Práctica y quiz: la pestaña de práctica genera ejercicios de completar oraciones a partir del diálogo. Además, el botón “Quiz rápido” crea un test de 10 preguntas sobre las frases clave, con retroalimentación inmediata y puntuación. También puedes lanzar un quiz específico desde la pestaña de frases de cada diálogo
- Optimización: el contenido de los diálogos y las notas está codificado en el arreglo DATA dentro del script. Si necesitas añadir, editar o reemplazar diálogos, puedes modificar directamente ese objeto: cada diálogo tiene lines, notes y phrases. Los textos están en inglés y las traducciones en español, listos para copiar y pegar en el mismo formato.
